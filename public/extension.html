CHECK THE HYPE WHERE IT HAPPENS

A second opinion.
Beside every Reel.

The Chrome side panel reads the caption you’re viewing, checks it against live Gemini markets, and keeps a paste box within reach.

Download Chrome extension ↓

Install the hackathon build

  1. Download and unzip the extension.
  2. Open chrome://extensions in Chrome 116 or later and turn on Developer mode.
  3. Choose Load unpacked and select the unzipped folder that contains manifest.json.
  4. Open an Instagram Reel and click the Pocket Quant extension icon to open the panel.
  5. In Connection & privacy, set the API base URL to this website’s origin (or http://localhost:3000 for a local server).
  6. Choose Check this Reel. Turn on Auto to check new captions as you scroll.

Your text, on your terms.

Auto is off by default. Caption checking sends visible text to the configured API server. If Claude is configured, that text is sent to Anthropic for extraction. “Listen 12s” sends captured tab audio to ElevenLabs. We don’t scrape Instagram from the server, store recordings, or publish your cards. Audio requires a server with an ElevenLabs key.

Instagram’s layout can change. If a caption can’t be read, paste the prediction. The Instagram DM bot is a future feature, pending Meta review.
