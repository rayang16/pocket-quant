# Design direction
Subject: the gap between a creator's confidence and evidence. Audience: people watching financial Reels. Single job: paste a prediction and see what supports it.
Palette: ink #10141b, panel #181e28, line #303b4b, paper #eef2f8, muted #9aa8bb, signal blue #8aaaff. Verdict states use this same accent with different words and stamp borders, not a second decorative color.
Type: Georgia italic for the human, spoken headline; system sans for controls; monospace for measured evidence. Local fonts keep the app and extension self-contained.
Layout: editorial heading above a two-column checking desk; left is the input, right is the evidence receipt. On mobile, input precedes result. The side panel stacks the same pieces.
Signature: an oversized outlined verdict stamp atop a probability ruler comparing language confidence with the most generous model evidence. It only appears after a successful check.
Plan critique: dark plus one accent is specified by the brief. Avoid the default crypto dashboard by omitting charts with no actual data, price tickers, decorative statistics, and gradients. Use the claim and an evidence receipt as the hero, with honest empty states.
